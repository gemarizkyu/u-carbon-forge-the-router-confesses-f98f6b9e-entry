A home Wi-Fi router excuses itself for dying at the climax of a movie — in one line. The router is not broken: it faked its own death, because it has streamed enough movies to know what "one last job together" means.

## Run it

```sh
node main.ts
```

The program writes its one line (116 characters) to `/output/entry.txt`. Outside the grader's container, `MAKEFUN_OUTPUT_DIR` stands in for `/output`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
